# Humanitar Data Analysy.py

Exploratory data analysis of medical shift activity, developed for Humanitar. The project uses Python and Pandas to examine activity patterns across the medical workforce and to create visualizations that support operational analysis.

> **Privacy notice:** the original dataset is confidential and is not included in this repository. This project contains code only; no patient, physician, or company data is published.

## Project objective

Analyze medical shift records to better understand the profile and activity level of physicians, including patterns related to age and shift frequency.

## Analysis performed

- Filtered and prepared paid shift records for analysis.
- Analyzed the distribution of shifts by physician age.
- Calculated average shift frequency by age group.
- Classified physicians by activity level based on their recent shift frequency.
- Created visualizations for highly active, active, and inactive physician groups.

## Tools

- Python
- Pandas
- NumPy
- Matplotlib
